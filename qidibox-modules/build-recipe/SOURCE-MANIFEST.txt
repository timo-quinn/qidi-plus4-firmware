QIDI Box modules — rebuilt from QIDI's GPLv3 source
===================================================

These binaries are compiled from QIDI's own GPLv3 Box source plus the documented
compatibility patch below, NOT from any QIDI binary. Two targets are provided:

  cp312-aarch64/  CPython 3.12 / aarch64 — for the Cartographer/Survey fix
                  (klippy-env upgraded to Python 3.12).
  cp37-aarch64/   CPython 3.7 / aarch64  — matches the stock QIDI host
                  (Debian 10 Buster). An open, rebuildable equivalent of what
                  QIDI already ships; not needed for the Cartographer fix.

See ../README.md.

NOTE: A Cython build is not bit-for-bit reproducible across hosts (embedded
paths, timestamps, and compiler differences vary). The artifact hashes above
identify these specific builds; a rebuild will match behavior, not necessarily
the hash. Verify behavior, not the hash.

Verification performed
----------------------
  - box_extras.so imports successfully under its build Python (3.12 and 3.7).
  - verify-box-extras.py confirms ToolChange.is_tool_change initializes false,
    becomes true at TOOL_CHANGE_START, and returns false at TOOL_CHANGE_END in
    both compiled targets.
  - The cp312 build is rejected under CPython 3.11 with
    "undefined symbol: PyUnstable_Code_NewWithPosOnlyArgs", confirming binaries
    are bound to their build ABI. A cp37 build is likewise 3.7-only.
  - box_rfid.so uses "from . import bus" and must be loaded by Klipper as
    extras.box_rfid (its normal loader path), not as a bare top-level module.
